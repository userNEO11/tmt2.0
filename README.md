# Balwant Super TMT Official Website

> **सरिया नहीं, फौलाद है ये** | Official Brand, Technical & Dealership Portal for Balwant Super TMT (Fe 550D / Fe 600 / CRS).

---

## 🛠️ Tech Stack
- **Frontend**: React 19 + TypeScript + Vite + Tailwind CSS + Lucide Icons + Motion
- **Backend / Static Server**: Node.js + Express
- **Build Output**: Production SPA in `/dist`

---

## 🚀 Local Development

1. **Install dependencies:**
   ```bash
   npm install
   ```

2. **Start development server:**
   ```bash
   npm run dev
   ```
   Open `http://localhost:3000` in your browser.

---

## 📦 Production Build & Run

1. **Build the production bundle:**
   ```bash
   npm run build
   ```

2. **Start the production server:**
   ```bash
   npm start
   ```

---

## 🌐 Deploy to Hostinger via Git (hPanel)

1. Go to **Hostinger hPanel** -> **Advanced** -> **Git**.
2. Paste your GitHub repository URL (`https://github.com/<your-username>/<repo-name>.git`).
3. Branch: `main`
4. Directory: `/public_html`
5. Click **Create & Deploy**.
6. If using Node.js hosting, ensure startup file is set to `server.js` or build files are placed in `public_html`.
